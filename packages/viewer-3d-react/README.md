# @holodeck/viewer-3d-react

Read-only **3D React viewer** for Holodeck `SceneFile` documents. Uses React Three Fiber (scaffold in progress).

Pair with [`@holodeck/editor-2d-react`](../editor-2d-react) for 2D editing and external importers (e.g. [`holodeck-importer-brainboard`](../../../holodeck-importer-brainboard)).

```tsx
import { HolodeckViewer3D } from '@holodeck/viewer-3d-react';

<HolodeckViewer3D scene={scene} height="80vh" />
```
